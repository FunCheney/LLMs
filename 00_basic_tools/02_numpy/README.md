
### 环境

1. 查看环境
```python
conda info
```
```python
 conda env list
```
2. 创建环境
```angular2html
conda create -n <环境名> python=<版本号>
```
3.激活/切换 环境
```angular2html
conda activate <环境名>
```
4.回到系统
```angular2html
conda deactivate
```
5，删除环境
```python
conda remove -n <环境名> --all
```
