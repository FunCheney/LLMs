### Function Calling 是什么
Function Calling（也叫 Tool Use）是 大模型 API 层的能力：
1. 应用把一组函数/schema 告诉模型 
2. 模型根据用户问题，输出结构化 JSON：{ "name": "grep", "arguments": { "pattern": "..." } } 
3. 应用自己去执行这个函数，把结果塞回对话 
4. 模型继续生成回答

特点：
* 只定义「模型如何选工具、传参数」 
* 不规定工具从哪来、怎么部署、怎么复用 
* 每个应用通常自己写工具、自己执行 
* OpenAI / Anthropic / Google 等各家 API 都有类似能力，细节略有差异

### 工程意义
1. 解耦：模型只负责要不要查，不负责怎么查
2. 智能调度：实现多工具协同，条件判断，链式调用
3. 易于扩展：新增工具无需改主逻辑，只需注册
4. 可观察性：追踪每一步决策和动作
5. 安全性：可在执行前审查 tool_call 参数
6. 支持复杂流程：先查库存->再算价格->最后下单
