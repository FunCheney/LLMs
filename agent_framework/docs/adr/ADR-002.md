# Mock 做回放引擎，不做假 LLM

| 属性 | 值 |
|---|---|
| 编号 | ADR-002 |
| 周次 | W1 |
| 状态 | Accepted |

## 决策

MockLLMClient 不是 `return LLMResponse(...)` 的假 LLM——它是 replay 引擎，回放 wire 原文，复用真 adapter 的 parse_response 与 Assembler。自己跟自己对答案 = 假绿。

## 替代方案

直接 `return LLMResponse(text='ok')`：简单但测不出解析 bug；用真实 API 烧钱且不稳定。

## 证据

W3 conformance tests 全用 httpx.MockTransport 走真实薄壳，零网络依赖。W1 起跑 278 条，W12 达 1471 条，全程无网络调用。

## 代价

写新 adapter 时要同时写 wire fixture 文件；fixture 要和真 API 响应一致（字段名/类型/嵌套结构）。
