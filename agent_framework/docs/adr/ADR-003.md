# Adapter 禁止重试、日志、业务判断

| 属性 | 值 |
|---|---|
| 编号 | ADR-003 |
| 周次 | W1 |
| 状态 | Accepted |

## 决策

重试、路由、熔断、并发闸门全在 LLMGateway 里。Adapter 只负责把 HTTP 变成 LLMResponse。在 adapter 里重试 = 一次 gateway.chat 被重试两次（叠加），上游调用数不可预测。

## 替代方案

adapter 自带重试（很多 SDK 默认这么做）；gateway 不做重试由调用方决定。

## 证据

W11 混沌 7 场景: calls_after_open == 0; upstream_calls == threshold x chain x max_attempts。

## 代价

调用方需自己写重试逻辑（但 gateway 已封装，产品层不用写）。
