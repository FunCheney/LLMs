# 分层架构：单向依赖

| 属性 | 值 |
|---|---|
| 编号 | ADR-001 |
| 周次 | W1 |
| 状态 | Accepted |

## 决策

五层架构（LLM 适配 → 客户端编排 → 上下文/护栏 → 服务 → 产品）严守单向依赖：上层 import 下层，下层不知道上层存在。框架的 `__init__.py` 是公共面，产品不穿实现模块。

## 替代方案

扁平结构（产品直接调 httpx + 手写 prompt）；六边形架构（端口与适配器分离，但对此项目量级引入不必要的间接层）。

## 证据

W12 audit: `api_audit.py --check` = 0 泄漏 / 0 空壳。`grep 'from agent_framework.' apps/` 无深层 impl 路径。

## 代价

每个能力包要 maintain `__all__`；新增调用点要跑审计才能确认公共面。
