# pgvector over Qdrant / FAISS

| 属性 | 值 |
|---|---|
| 编号 | ADR-005 |
| 周次 | W5 |
| 状态 | Accepted |

## 决策

向量存储用 pgvector（已有 PostgreSQL）。不上 Qdrant（少一个组件 = 少一处故障面）；不上 FAISS（进程内、不可共享、重启丢索引）。

## 替代方案

Qdrant（专用向量库，但多一个进程）；FAISS（快但不持久化）。

## 证据

W5: Recall@K 延迟 <2ms; 查询评测 10/10 PASS (`evals/history/2026-W48.json`)。

## 代价

pgvector 的 HNSW 参数调优不如 Qdrant 精细；100M+ 向量时性能可能不够（本项目量级不触及）。
