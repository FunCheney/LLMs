# 产品只依赖公共 API

| 属性 | 值 |
|---|---|
| 编号 | ADR-004 |
| 周次 | W1 → W12 |
| 状态 | Enforced |

## 决策

apps/ 的所有 import 必须命中框架 `__init__.py` 或子包 `__all__`。穿透实现模块 = 隐形 breaking change。`api_audit.py --check` 在 CI 里守着这条。

## 替代方案

允许产品 import 实现（初期快，后期不可控）；用 protocol/interface 强约束（过度设计）。

## 证据

W12 D1 后 `grep 'from agent_framework.llm.client' apps/` = 0 行。审计脚本报 0 泄漏、0 空壳、子包未导出 = 0。

## 代价

公共面必须 commit 稳定；新增符号要在 `__all__` 里登记。
