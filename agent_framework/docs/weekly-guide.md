# 12 周执行导航（W1–W12 逐日引导框架索引）

> 本文件是所有周文档的**总目录与用法说明**。每份 `docs/wN/wN-tasks.md` 都用同一套骨架，
> 让你可以"照着做 → 自查 → 交给我 review"地推进 12 周，而不用每周重新理解协作方式。

## 角色约定（贯穿 12 周，来自 `docs/w1/w1-tasks.md` 第 3 行）

- **我（AI）出**：架构、接口骨架（签名/数据结构/算法步骤）、验收标准、易返工点
- **你写**：函数体、实现、测试
- **我不代写**：文档只给"能引导你完成的框架"，不给可直接运行的实现
- 每完成一个 Gate，把仓库状态给我，我按 `docs/architecture.md` + ADR 逐条 review

## 三条贯穿 12 周的铁律（每周文档都会重复强调）

1. **重试只在 `LLMGateway`（ADR-003）**：入口背压(W2)、熔断器(W11)、工具执行(W8) 都不许造第二次重试
2. **指标只从 `RequestLog` 读，不自己 `time.monotonic`**：否则 W1/W2/W3/W11/W12 的曲线和成本看板口径全乱
3. **上游鉴权失败映射 502，不是 401（ADR-005）**：我方 401（W10）只表示调用方没过我方鉴权，两者严格区分

## 用法建议

1. 每周开始前先读该周文档的「承接面」和「Gate 0」，确认前置已合流
2. 每天按「你要做的事」勾选推进，卡住时看「引导骨架」里的签名与算法步骤（**函数体自己写**）
3. 每天结束跑「自检」，周末过「Gate N 验收表」再交给我
4. **周五合流仪式不可跳过**（ROADEMAP §3.2）——12 个数据点连成曲线是作品集最硬的证据
5. P3 深入档只在 **W4/W8/W12 末**按"余量 ≥15h"决策，默认档一律先完成
