## 推荐实施顺序
### 第一阶段：可评估的单知识库 MVP
* 选择一个业务场景。 
* 接入一种真实文档。 
* 保留标题、章节和页码。 
* 实现向量检索、关键词检索和引用。 
* 建立第一批 Golden Dataset。 
* 先测出基础 Recall@K 和答案正确率。
### 第二阶段：检索质量
* 增加查询改写。 
* 混合检索。 
* Rerank。 
* 父子 Chunk。 
* 无答案判断。 
* 文档冲突与时效处理。
### 第三阶段：企业数据治理
* 用户认证。 
* 租户、部门、角色权限。 
* 增量更新和删除。 
* 文档版本管理。 
* 审计与敏感信息处理。
### 第四阶段：生产服务
* API 服务。
* PostgreSQL/检索存储。
* 异步入库任务。
* 超时、重试、限流。
* Docker、CI/CD。
* 日志、Trace、Metrics、告警。
### 第五阶段：接入 Agent
* 把 RAG 做成只读 Knowledge Tool。
* Agent 根据任务决定何时检索。
* 引用随 Agent 最终回答一起返回。
* 高风险业务操作继续走专门工具和人工审批。
